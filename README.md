# 电梯与楼层导向铭牌 · 触觉版压点前预检

纯浏览器单页应用（Vue 3 + TypeScript + Vite）。制版员键入短句并选择每行方数（4–20），
页面按仓库内固定编码表逐方预览六点点位、数字符位置、换行与总方数，压点前直接发现差错。

**不请求任何在线转换接口**：编码、排版全部在浏览器本地完成。

## 编码规则（固定表，见 `src/lib/braille.ts`）

六点编号，左列 1、2、3，右列 4、5、6：

```
1 ─ 4
2 ─ 5
3 ─ 6
```

| 字符 | 点号方 |
| --- | --- |
| 一 二 三 四 五 六 七 八 九 零 | `1` `12` `14` `145` `15` `124` `1245` `125` `24` `245` |
| 半角 0–9 | 沿用对应中文数字编码（0→零`245`，1→一`1`，…，9→九`24`） |
| 数字符（每段连续半角数字前自动插入一方） | `3456` |
| 逗号 `，` / 句号 `。` / 连字符 `-` / 空格 | `2` / `256` / `36` / 空方 |

- 半角数字串遇到**任何非数字字符**即结束；下一段数字前重新插入数字符 `3456`。
- 中文数字不触发数字符。
- 允许字符仅限：`一二三四五六七八九零`、半角 `0-9`、空格、`，。-`。
- 排版：逐方填充，达到行宽换行，**不拆分编码方，也不补齐末行**。
- **非法字符、空文本或非法行宽（非 4–20 的整数）阻止全部输出。**

## 双稿核对

压点车间常收到内容相近的“审核稿”和“制版稿”，只看字面容易漏掉数字段变化
引起的数字符位移。页面顶部可切换到**双稿核对**模式：分别粘贴两份短句并点击
“发起核对”，页面复用同一固定编码器把两稿转成**带来源索引**的方序列，再由
比对服务做一套确定性的最短编辑对齐，逐项标出首个差异及后续插入、删除、替换，
并注明每方来自原稿第几个字；空方与数字符照常可辨认。

- 两稿完全一致时给出明确结论（总方数、无差异）。
- 任一稿为空或含非法字符时，**只在对应输入旁反馈出错位置并停止比对**，不产生差异表。
- 核对对象是一次双稿差异记录，不做行宽排版；单稿预检的输入、排版、总方数与错误阻断行为不受影响。

## 试压校准

换模或保养后，班组先压一张**六点试压片**，避免设备偏压影响随后生产的铭牌。
页面顶部可切换到独立的**试压校准**工作区：操作员为 1 至 6 号点分别录入一次
凸点高度（毫米）并点击“执行判定”，页面按点展示实测值、越界原因与整机结论。

- 单点合格范围固定为 **0.60–0.90 毫米**（含边界）；六点最大值与最小值之差（极差）
  **不超过 0.15 毫米**（含边界）。
- 空值（缺项）、非数字、非有限数、**超过两位小数**或**非正数**都在对应点位就地提示，
  并**停止判定**（不产生任何阈值结论）。
- 读数全部有效但阈值不满足时，正常生成 **“需调机”** 结果并逐项列出越界原因，
  与输入错误严格区分；阈值全过则为 **“合格”**，可以投入铭牌压点生产。
- 未提交草稿自动保存在浏览器 localStorage，刷新后重新进入工作区即恢复；
  一次成功判定（合格或需调机）会把屏幕上的六点输入与判定读数作为**同一个完整快照**保存，刷新后仅在两者一致时恢复结论。任一读数再被修改后上次结论立即失效。
- 不一致、缺项、超长、旧版/未知版本或字段损坏的存档会明确告警，只展示可取证读数且不显示“合格/需调机”结论；用户重新完成有效判定前不会自动覆盖原存档。写入配额或权限失败时也会告警，并保留最近一次可恢复记录。
- 校准会话是完全独立的工作区：**不读取也不改写**单稿预检与双稿核对的任何输入或结果，
  全部计算仍在本机完成，离线可用。

## 压点放行

制版员完成铭牌文字预检后，只有**当前六点试压判定合格**才允许交付一份可复核的压点放行单。
页面顶部可切换到独立的**压点放行**工作区，它**只读**复核单稿预检与试压校准的当前结果，
本身不录入任何数据：

- 放行闸门同时要求：单稿预检合法且有逐方输出；最近一次校准是本页面会话内**新完成**的
  **“合格”**判定；屏幕上的六点读数与判定读数逐字一致；存档版本相符且不处于保护态。
  **“需调机”、受阻（无效）读数、非法文字 / 非法行宽、未重新判定的旧版（v1）校准存档**
  都会逐条列明阻断原因，不能放行。
- 点击“签发压点放行单”后，系统把**合法单稿的原文、行宽、逐方编码与排版结果**，连同
  **同一次合格校准判定及其六点原始读数**固化为一张**不可变快照**（递归冻结）。
  每张放行单有独立标识（`PF-日期-时间-随机后缀`），页面在“当前可放行”区与历史区
  都完整展示其来源快照，可逐项只读复核。
- **当前可放行状态立即失效**：放行后修改单稿文字、行宽或任一校准读数
  （或在其它标签页改、或校准结论不再合格），当前授权立刻撤销并明确提示；
  但历史放行单**始终只读保留**，草稿改动不会覆盖任何已签发单据，需要时重新签发新单。
- **刷新与跨标签页**：放行单存档（只追加）持久化在 localStorage。刷新或跨标签页收到
  更新时，只依据**完整、版本相符**的记录恢复历史展示；旧单据只进入历史只读复核，
  **不会被自动当作当前授权**，如需放行必须在当前状态重新满足条件后重新签发。
- **历史只增不减**：存档**不设条数上限**——累计到第 201 张、第 2001 张时最早的放行单
  仍然逐字可查，任何已签发单据都不会被静默顶掉。
- **双页签交错写入不丢单**：两个页签同时签发时，追加采用“读最新存档 → 合并 → 写回 →
  再读校验”的乐观并发循环；每个页签还**认领自己签发过的单据**，收到跨页签 storage
  更新时若发现存档整表缺单（另一页签用旧列表整体覆盖），立即把缺单合并补写回去并
  明确提示“历史已自动补齐”。两张、多张交错单据最终都在历史中可只读复核。
- **编号冲突必须有明确结果**：相同编号且快照内容逐字一致视为同一张单据（幂等成功）；
  相同编号但**内容不同**是不可调和冲突——本次签发被拒绝并明确告警，历史编号原单据
  逐字保留，当前展示内容不会冒充历史原件，需重新签发取得新编号。
- **失败保护**：放行存档 JSON 损坏、字段缺失、版本不符或单据无法用领域服务重算一致时，
  明确告警并转入保护态——保留最近一次完整记录（含冗余备份）只读取证、拒绝任何新写入、
  不覆盖原存档；写入配额 / 权限失败、持续交错重试超限时同样明确告警，不产生“伪签发”，
  原存档逐字保留。
- 原单稿预检、双稿核对与识读训练的输入与结论均保持不变；放行页只共享单稿输入字符串
  与校准判定结论，不引入任何新的编码或排版规则。

## 更正补发

已签发的放行单若所用文字有误，**不改写原单**，而是在历史详情点击“以此单更正”
补发一张独立编号的更正单，原单继续只读保留供换班追溯。

- 入口在历史单据详情：点击“以此单更正”后先弹出确认框，操作员**明确确认**后才把
  原单文字与行宽带入共享的可编辑草稿（覆盖当前草稿）；确认前草稿不被触碰，
  随时可取消。更正规程状态挂在放行会话单例上：切到单稿预检页修改文字、切回弹窗仍在。
- **更正必须重新通过现有放行闸门**：修正后的文字与行宽重新通过编码与排版校验，
  试压校准必须是本会话**新完成的一次“合格”判定**（读数改动后必须重新判定），
  并且必须填写**非空更正原因**，三者齐备才签发更正单。
- 更正单有独立编号，并在自身固化一条**不可变关联** `correction`：非空更正原因
  与**可选**的原单编号（未关联时为 null）。关联只写在新单上，**原单内容绝不改写**；
  关联数据递归冻结，结构校验拒绝空原因、错误类型与自指关联。
- 历史页展示**更正链与当前状态**：线性链的唯一终端标记为“更正链现行版本”，
  其上游标记“已被更正单 X 取代”；更正关联指向存档外编号时标记关联缺失。
  **绝不凭时间先后悄悄选出现行版本**——两张更正单同时指向同一原单（跨页签
  交错合并后的分叉）时，历史区顶部明确提示“更正链存在分叉冲突”，分叉点标记
  “不作现行认定”、全部分支标记“分叉分支”，自动认定现行单立即停止，
  但三张（及更多）原件全部保留取证。
- 链分析是纯函数（`src/lib/correction.ts`），与领域校验、只追加存档、共享会话、
  页面展示共用同一份 `correction` 字段；分叉检测只看关联结构，不看签发时间。
- **旧格式存档照常读取**：没有 `correction` 字段的历史单据按原格式完整恢复、
  只读复核，并可在此基础上补发更正。
- 更正单与首次签发共用只追加存档与失败保护：存档损坏 / 未知版本 / 关联字段损坏
  转入保护态、拒绝写入并保留原档；配额 / 权限失败明确告警，不产生伪签发。


## 识读训练

新上岗制版员独立操作前需完成点位识读练习。页面顶部可切换到独立的**识读训练**工作区：
点击“开始训练”后，依次查看由既有固定编码表生成的**十张盲文方卡片**，每题从四个字符
选项中作答，提交后立即显示正确字符与点号说明（第几点凸起），局末汇总答对数与错题。

- 题目由领域层按**可注入种子**生成：同一种子得到完全相同的题序与选项顺序；
  一局十题互不重复，每题四个选项且恰好一个正确字符。
- 训练服务维护当前题号、作答记录与成绩契约：**每题只允许提交一次**，
  局次完成前**阻止重复开局**；题目生成异常时页面给出**无法开局**反馈，不出现空白题卡。
- 局次**不做本地保存**：刷新页面或离开本工作区即直接结束未完成局次。
- 识读训练是完全独立的工作区：**不读取也不改写**单稿预检、双稿核对与试压校准的
  任何数据，全部计算仍在本机完成，离线可用。
